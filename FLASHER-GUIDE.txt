TamaPoke 香港繁體中文版公開安裝程式指南
======================================

重要事項
--------
公開安裝程式、儲存庫及瀏覽器套件不包含寶可夢精靈圖、實際額外音效，
或已整合使用者資產的完整韌體。隨附的 sample_Additional_assets.zip
只有 ccs21 自製的基本示範圖片和 0 位元組音效標記。

請勿重新散佈安裝程式製作的完整韌體（*-full.bin）、自備資產 ZIP 或
精靈圖快取。請只加入你自行製作或有權使用的素材。

Windows 安裝步驟
----------------
1. 將 TamaPoke-Flasher-v*.exe 和 sample_Additional_assets.zip 放在同一資料夾。
2. 喚醒裝置，使用 USB-C 資料線連接 Windows 10/11 電腦。
3. 執行安裝程式，按「重新整理」確認資產狀態和 COM 埠。
4. 按「自動檢查並安裝」，並依提示選擇如何處理相容的儲存資料。

此安裝程式支援 Waveshare AMOLED 1.75（16 MB）及 1.75C（32 MB），會按容量
識別裝置。初次安裝需要互聯網下載工具和精靈圖。詳情請參閱：
docs\INSTALLATION_GUIDE.md

使用自備資產
------------
複製 sample_Additional_assets.zip，將複本命名為 Additional_assets.zip，再只
修改複本。安裝程式優先使用自備 ZIP；缺少或損壞的項目會先詢問是否以樣本
補上。MP3 和 WAV 不可同時提供同一音效。

視覺資產（PNG）：
Visual\L01.png                 載入畫面（建議 350x350）
Visual\B01.png / B02.png       捕捉用關閉／開啟精靈球（建議 160x160）
Visual\S01.png / S02.png       卡比獸頭部手臂／身體圖層（建議 350x350）
Visual\S03.png / S04.png       卡比獸腳部圖層／成功畫面（建議 350x350）
Visual\D01.png 至 D04.png      地鼠出現動畫（每張必須 22x17；D01 是空洞）

音效檔案名稱和長度等其他格式要求，請參閱 docs\ADDITIONAL_ASSETS_GUIDE.md。
S01 至 S04 應使用相同 350x350 畫布和圖像位置；音效請只提供 MP3 或 WAV 其中一種。

安裝程式只會在你的電腦處理自備素材，不會將檔案上載至外部伺服器。首次執行
下載或產生的檔案會放在執行檔旁的 TamaPoke-Flasher-Data 資料夾。

瀏覽器安裝方式
--------------
瀏覽器安裝只支援 Waveshare AMOLED 1.75，不支援 1.75C。需要 HTTPS 網頁、
支援 Web Serial 的桌面版 Chrome 或 Edge，以及 USB-C 資料線；瀏覽器基本韌體
不含精靈圖、LittleFS 資產或使用者素材。完整步驟和限制請參閱
docs\INSTALLATION_GUIDE.md。
