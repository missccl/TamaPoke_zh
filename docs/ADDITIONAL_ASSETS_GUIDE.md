# Additional_assets.zip 額外資產指南

公開 Windows 安裝程式附有 `sample_Additional_assets.zip`，內含 ccs21 自製示範圖片及 0 位元組音效標記。你可以複製樣本並把有權使用的圖片或音效放進 `Additional_assets.zip`。安裝程式會在你的電腦上轉換資產；它不會上載你的檔案。

不熟悉安裝流程的話，請先閱讀[安裝指南](INSTALLATION_GUIDE.md)。建議以[樣本 ZIP](../samples/sample_Additional_assets.zip)為基礎；不修改樣本也可直接安裝。

## 使用權

只可使用你自行製作、獲准嵌入及修改，或明確允許用於非商業軟件的素材。免費下載或個人欣賞許可不代表可把素材嵌入軟件。請自行確認權利和署名要求，並且不要重新散佈含有第三方素材的 `Additional_assets.zip` 或 `*-full.bin`。

## ZIP 內容

ZIP 內必須包含 `Visual` 和 `Audio` 兩個資料夾及以下檔案。音效每項只可使用 MP3 或 WAV 其中一種；不使用的音效保留樣本中的同名 0 位元組檔案。

```text
Additional_assets.zip
├─ Visual
│  ├─ L01.png
│  ├─ B01.png
│  ├─ B02.png
│  ├─ S01.png
│  ├─ S02.png
│  ├─ S03.png
│  ├─ S04.png
│  ├─ D01.png
│  ├─ D02.png
│  ├─ D03.png
│  └─ D04.png
└─ Audio
   ├─ P.mp3 或 P.wav
   ├─ Care.mp3 或 Care.wav
   ├─ C.mp3 或 C.wav
   ├─ L.mp3 或 L.wav
   ├─ E.mp3 或 E.wav
   ├─ B.mp3 或 B.wav
   ├─ BAT.mp3 或 BAT.wav
   ├─ MIN.mp3 或 MIN.wav
   └─ MAR.mp3 或 MAR.wav
```

檔名和資料夾名稱請按上面拼寫。壓縮檔內可有一層額外的上層資料夾。若同一音效同時有 MP3 和 WAV，安裝程式會報重複錯誤；請刪除其中一個。

## 更換樣本資產

1. 複製 `sample_Additional_assets.zip`，把複本命名為 `Additional_assets.zip`。
2. 解壓複本，更換 `Visual` 中的 PNG；把音效標記替換為同名 MP3 或 WAV。
3. 不使用的音效請保留原有 0 位元組檔案；使用音效時，刪除同名的另一種格式。
4. 重新壓縮 `Visual` 和 `Audio` 兩個資料夾，確保它們位於 ZIP 根目錄或只有一層上層資料夾。
5. 將 `Additional_assets.zip`、原始 `sample_Additional_assets.zip` 和安裝程式放在同一資料夾。

使用者 ZIP 優先於樣本 ZIP。若有缺漏或損壞檔案，安裝程式會先詢問是否從樣本補上。重複項目不會自動刪除。更換資產後，按安裝程式中的「重新整理」。

## 圖片規格

一般圖片使用 PNG，重要圖像請置於畫布中央並保留透明度。除 D01–D04 外，安裝程式會縮放圖片；但不會自動修正錯誤比例或圖層位置。輸出會轉為 RGB565/RLE，細微色差可能消失。

| 檔案 | 用途 | 建議輸入 | 裝置輸出 | 背景 |
| --- | --- | --- | --- | --- |
| `L01.png` | 休眠喚醒載入畫面 | 350×350 | 350×350 | 合成黑色背景 |
| `B01.png` | 關閉的精靈球 | 160×160 | 160×160 | 合成黑色背景 |
| `B02.png` | 開啟的精靈球／捕捉失敗 | 160×160 | 160×160 | 合成黑色背景 |
| `S01.png` | 卡比獸頭部和手臂，最底層 | 350×350 | 116×116 | 透明 |
| `S02.png` | 卡比獸身體，中間層 | 350×350 | 116×116 | 透明 |
| `S03.png` | 卡比獸腳部，最上層 | 350×350 | 116×116 | 透明 |
| `S04.png` | 卡比獸成功畫面全身圖 | 350×350 | 116×116 | 透明 |
| `D01.png`–`D04.png` | 地鼠出現動畫 | **22×17（必須）** | 22×17 | 透明 |

### L01、B01 和 B02

`L01` 會顯示於圓形螢幕中央；重要文字和圖像建議離邊緣至少 20 像素。`B01` 和 `B02` 必須使用相同畫布和中心點，否則捕捉動畫中精靈球會移位。

### S01 至 S04

四張圖必須使用完全相同的 350×350 畫布、原點及比例。建議複製同一張完成圖，再只把各圖層不需要的部分設為透明，不要移動剩餘部件。

```text
最上層：S03 腳部
中間層：S02 身體（一般擊打時會晃動）
最底層：S01 頭部和手臂
成功時：以 S04 全身圖取代三層
```

把 S01、S02、S03 疊在一起應可還原完整圖像。安裝程式會將各層縮至 116×116，遊戲中再放大 3 倍。避免白色背景、灰色格紋和細小半透明陰影；需要透明的部分請使用 PNG Alpha。

### D01 至 D04

四張圖都必須精確為 22×17 像素；不會自動縮放。D01 是沒有地鼠的空洞，也用於地鼠出現前。依 D01 → D02 → D03 → D04 的順序繪製，並讓地洞及地鼠中心保持相同水平位置。毋須另備 DD.png。

## 音效規格

輸入可用 MP3 或 WAV；輸出會轉為 16 kHz、單聲道 IMA-ADPCM。立體聲會合併成單聲道，較長音檔會按下表截取並淡出。長音檔請自行先剪去多餘靜音。

| 名稱 | 用途 | 最短輸入 | 使用片段／淡出 |
| --- | --- | --- | --- |
| `P` | 特別夥伴出場 | 0.1 秒 | 去除開頭靜音後最多 4 秒 |
| `Care` | 照顧提醒 | 0.1 秒 | 去除開頭靜音後最多 10 秒 |
| `C` | 捕捉成功 | 0.1 秒 | 開始最多 10 秒／淡出 0.1 秒 |
| `L` | 低體力提醒 | 0.1 秒 | 開始最多 6 秒／淡出 0.05 秒 |
| `E` | 進化 | **6.2 秒** | 從第 1 秒開始 5.2 秒／淡出 2 秒 |
| `B` | 告別 | **10 秒** | 開始 10 秒／淡出 2 秒 |
| `BAT` | 野生／通訊對戰 BGM | **60 秒** | 開始 60 秒／淡出 5 秒 |
| `MIN` | 小遊戲 BGM（不含散步） | **60 秒** | 開始 60 秒／淡出 5 秒 |
| `MAR` | 通訊配對 BGM | **15.5 秒** | 開始 15.5 秒／淡出 5 秒 |

保留 0 位元組音效標記即可略過該音效；視遊戲場景而定，韌體可能使用合成音效或不播放背景音樂。對戰 BGM 超過 60 秒後會循環；音樂長度不會延長遊戲動畫。

## 安裝程式檢查及錯誤排解

安裝程式會檢查 21 個必需資產、重複項目、損壞檔案、PNG／音效格式、D01–D04 尺寸、指定背景音樂長度，以及 ZIP 路徑和解壓大小限制。資產內容的 SHA-256 會用於快取：內容相同時重用轉換結果，變更後則重新產生。

- **找不到檔案：** 確認 ZIP 內有 `Visual` 和 `Audio`，並檢查檔名有沒有重複副檔名（例如 `L01.png.png`）。
- **重複音效：** 每個音效名稱只保留 MP3 或 WAV 一種，並刪除備份資料夾內的同名檔案。
- **卡比獸圖層錯位：** 重新以相同畫布和中心位置製作 S01–S03。
- **圖片出現白色方塊：** 檢查 PNG Alpha；L01、B01 和 B02 則會合成黑色背景。
- **更新後仍使用舊資產：** 按「重新整理」；必要時關閉安裝程式後只刪除 `TamaPoke-Flasher-Data\Cache\additional`，再重新執行。

整體圖片位置可參閱[資產配置圖](ASSET_LAYOUT.svg)。
