TamaPoke

把基本韌體寫入 Waveshare ESP32-S3-Touch-AMOLED-1.75（16 MB）。用 Chrome 或 Edge，插上 USB-C，即可安裝。

此瀏覽器不支援 Web Serial。請改用最新版桌面 Chrome 或 Microsoft Edge。

Web Serial 需要 HTTPS（或 localhost）。請勿以 file:// 開啟本頁。

只支援 1.75（16 MB），不適用於 1.75C。

1.75

安裝前準備

確認線材、瀏覽器與板子型號無誤後，再按上方按鈕。

  1. 使用最新版桌面 Chrome 或 Microsoft Edge，並以 HTTPS 開啟此頁。
  2. 喚醒 Waveshare AMOLED 1.75，以可傳輸資料的 USB-C 線連接電腦。
  3. 按「連接裝置並安裝」，選擇 ESP32-S3 序列埠，期間請勿拔線。

公開基本韌體的限制

此線上安裝只寫入不含資產的基本韌體，不會下載精靈圖或建立 LittleFS。

首次安裝後可能看不到寶可夢精靈圖。需要精靈圖或自備資產時，請改用 Windows 整合安裝程式；素材只在你的電腦上準備，不會上載到本頁。

安裝會更換韌體與分割區表。瀏覽器安裝不提供儲存資料備份；重要資料請先自行備份。
