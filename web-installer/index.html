此安裝程式只支援 Waveshare ESP32-S3-Touch-AMOLED-1.75（16 MB）。

安裝前準備

  • 使用最新版桌面版 Chrome 或 Microsoft Edge，並以 HTTPS 開啟此頁面。
  • 使用可傳輸資料的 USB-C 線，連接裝置後按上方按鈕，再選擇 ESP32-S3 序列埠。
  • 安裝期間請勿拔除裝置。若瀏覽器未顯示序列埠，請檢查 USB 線、連接埠及系統權限。

公開韌體限制

這是沒有附帶資產的公開基本韌體。它不會安裝寶可夢精靈圖、額外音效或使用者自備資產；首次安裝後可能看不到精靈圖。此頁只寫入基本韌體，不會建立含資產的 LittleFS 映像。

如要安裝精靈圖或自己的資產，請使用 Windows 版整合安裝程式；資產會在你的電腦上準備，並不會上載至本頁。

只適用於 Waveshare AMOLED 1.75，請勿用於 1.75C 或其他 ESP32-S3 裝置。安裝會更換韌體與分割區表；重要資料請先備份。
