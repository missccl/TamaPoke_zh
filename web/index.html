TamaPoke 香港繁體中文版

基於 Loaram/TamaPoke_ko · 1025 種 · 9 個地區
只支援 Waveshare ESP32-S3-Touch-AMOLED-1.75（需要 microSD 卡）

1安裝中文韌體

用可傳輸資料的 USB 線把裝置連接到電腦，按下方按鈕並選擇序列埠。更新時不要勾選 Erase device，直接按 Next，存檔便會保留。

需要電腦版 Chrome 或 Edge。請用 HTTPS 或 localhost 開啟。

此瀏覽器不支援 Web Serial，請改用電腦版 Chrome 或 Edge，並以 HTTPS 開啟本頁。

看不到序列埠

按住 BOOT，按一下 RESET，再放開 BOOT。充電專用線不能使用；請關閉其他安裝視窗和序列埠監視器，並避免使用 USB 集線器。

安裝工具的彈出視窗為英文。順序：Install → 不勾選 Erase device → Next。

2安裝精靈圖

先把 microSD 卡插入裝置，再按「連接裝置」。

「全部」會安裝 9 個地區和形態包。形態包需要支援形態變化的韌體。

連接裝置後便可選擇要安裝的地區。



安裝自製精靈圖檔案




3中斷連接後重新啟動
看到安裝完成的訊息後，按「中斷連接」並重新啟動裝置。
